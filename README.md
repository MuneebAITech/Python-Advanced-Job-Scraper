\# Advanced Job Scraper



A Python automation project that scrapes job listings from a website and exports filtered results to Excel and CSV files.



\## Features



\* Job Scraping using Requests and BeautifulSoup

\* Keyword-Based Filtering

\* Duplicate Removal

\* Date Posted Extraction

\* Apply Link Extraction

\* Excel Export

\* CSV Export

\* Timestamped Output Files

\* Logging System

\* Statistics Summary

\* Automated Report Generation
